# Tecno Oro

Tienda de celulares, accesorios y servicios.

- `frontend`: Angular
- `backend`: API Spring Boot

Publicado en:

- https://tecno-oro-nube.vercel.app
- https://tecno-oro-api-production.up.railway.app

En la Mac el backend usa H2 y el frontend apunta a `http://localhost:8080/api`. En producción la API usa PostgreSQL y el frontend llama a Railway por HTTPS.

Cuentas de prueba: `admin@tecnooro.com` / `admin123` y `maria.paredes@correo.com` / `cliente123`.

El correo de Gmail no va en el repositorio. En local se pone en `backend/config/correo.local.properties`.
